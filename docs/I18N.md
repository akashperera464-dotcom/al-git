# Verda · Multi-Language Support (i18next)

Tri-lingual UI: **English (en) · Sinhala (si) · Tamil (ta)**, implemented with
`i18next` + `react-i18next` across both the web PWA and the native Expo shell.

## Web App (React + Vite)

```
src/i18n/
├─ index.ts               # i18n init + LanguageDetector (localStorage)
└─ locales/{en,si,ta}.json
src/components/LanguageSwitcher.tsx   # globe dropdown (dark + light variants)
src/main.tsx                          # imports "./i18n" before App
```

- Detection order: `localStorage` → `navigator` → `<html lang>`, cached under
  the `verda.lang` key. The choice persists across sessions.
- The switcher is mounted in **both** the admin header and the mobile header
  (`src/components/Shell.tsx`).
- Translate any component:

```tsx
import { useTranslation } from "react-i18next";
const { t } = useTranslation();
<h1>{t("supplier.payments")}</h1>      // "Payment Tracker" / "ගෙවීම් ලුහුඬිය" / "கட்டண கண்காணிப்பு"
```

### Key namespaces
| Namespace | Examples (en) |
|---|---|
| `nav.*` | Estate Dashboard, Labor Management, Payroll System… |
| `roles.*` | Admin, Supervisor, Supplier + their titles |
| `supervisor.*` | Digital Attendance, Daily Work Allocation, **Leaf Weighing Entry** |
| `supplier.*` | **My Leaf Deliveries**, Smart Alerts Panel, **Payment Tracker** |
| `domain.*` | **Leaf Weights**, Attendance, Payments, Estate, Field… |
| `common.*` | Online/Offline, Retry, Loading, Language |

## Native Shell (React Native + Expo)

```
app/src/i18n/
├─ index.ts               # i18n + AsyncStorage persistence (same 'verda.lang' key)
└─ locales/{en,si,ta}.json
app/src/components/LanguageSwitcher.tsx  # native modal sheet switcher
```

- The native `LoadingScreen` and `OfflineScreen` are translated via `useTranslation`.
- A floating globe switcher overlays the WebView. Changing language there:
  1. updates the shell via `i18n.changeLanguage` + AsyncStorage, **and**
  2. injects `localStorage.setItem('verda.lang', code)` into the WebView and
     reloads — so the embedded PWA follows the same language instantly.

## Adding a new language

1. Add the locale file (`src/i18n/locales/xx.json` + the mobile copy).
2. Register it in `SUPPORTED_LANGUAGES` (`src/i18n/index.ts`) and `supportedLngs`.

> Role-specific keys (Attendance, Leaf Weights, Payments) live under
> `supervisor.*`, `supplier.*` and `domain.*` so each role's console renders in
> the selected language with no component changes.
